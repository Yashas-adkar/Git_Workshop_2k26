# Git & GitHub Workshop

This repository documents my learning and hands-on practice during a Git and GitHub workshop. It is a simple learning repository focused on understanding the basics of version control, repository management, commits, branches, and remote collaboration.

## About the Workshop

This repository was created as part of a workshop where I learned and practiced the fundamentals of Git and GitHub. The goal was to build confidence in using Git commands, understanding repository workflows, and managing project changes in a structured way.

## What I Learned

During this workshop, I practiced the core Git and GitHub concepts and commands that are essential for any beginner:

- `git init`
- `git status`
- `git add`
- `git commit`
- `git log`
- `git branch`
- `git switch`
- `git merge`
- `git remote`
- `git push`
- `git pull`
- `git clone`

These commands helped me understand how files move through the local repository workflow and how changes are shared with GitHub.

## Git Workflow

The basic Git workflow I learned is:

`Working Directory → Staging Area → Commit → Remote Repository`

In simple terms:

1. Make changes in the working directory.
2. Stage the files using `git add`.
3. Save the changes with `git commit`.
4. Push the updates to a remote repository with `git push`.

## Hands-on Practice
